# ふたつの灯 — Two Lanterns

二人で協力して地下迷宮を進む、ブラウザで遊べるオンライン協力アクション。
離れた場所の友達とも、**ルームコード**を伝えるだけで一緒に遊べます。

## 遊び方

| 操作 | キー |
| --- | --- |
| 移動 | W A S D |
| 攻撃（長押しで連続） | 左クリック |
| 回避（無敵） | Space / 右クリック |
| スキル | Q / E |
| 拾う・宝箱を開ける | F |
| キャラクター画面（装備・スキル習得） | Tab |
| 操作説明 / 音 | H / M |

- 一人が「ルームを作る」→ 画面右上の 5 文字のコードを相方に伝える
- 相方は「参加する」にコードを入れる（`https://…/?room=コード` のリンクでも入力済みで開けます）
- フロアの魔物を全滅させると転移陣が開く。二人で乗ると次の層へ。3 層ごとにボス
- 宝箱・敵から武器（6 種 × 5 レアリティ＋特殊効果）とスキルの巻物（7 種）がドロップ
- 倒れても相方がそばに立てば復活

## GitHub Pages で公開する

サーバーは要りません。2 人の通信は WebRTC（PeerJS）で直接つながります。

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身をアップロード（`index.html` がリポジトリの一番上に来るように）
3. リポジトリの **Settings → Pages** で Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
4. 1〜2 分後に `https://ユーザー名.github.io/リポジトリ名/` で遊べます。このURLを相方にも送るだけ

### ローカルで試す

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開く（`index.html` を直接ダブルクリックでは動きません）。

## 補足

- 接続の仲介に PeerJS の無料公開サーバーを使っています。ごくまれに会社・学校などの厳しいネットワークではつながらないことがあります
- 絵・音はすべてコードで描画・合成しているので、画像や音声ファイルはありません
